# MaaKaTiffin Hotfix

This package restores the complete MaaKaTiffin prototype:
- 5 km default service zone
- 20 km Weekend Specials
- Leaflet map with mother/seller pins
- Browser location button
- Distance calculated from selected/current location
- Search by mother, food, cuisine and area
- Menu + demo booking/payment
- Customer dashboard
- Seller/Mother dashboard
- Render-ready Flask server

## Deploy on Render

Build command:
pip install -r requirements.txt

Start command:
python app.py

The website listens on Render's PORT environment variable.
